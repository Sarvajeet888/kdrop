Fallback relay

Honest note

This page asks the server that serves it. If that server is completely down, this page will not load either — which is itself an answer, but not a graceful one. A status page hosted separately from the thing it monitors is the proper arrangement, and it is on the list.

There is no incident history here yet. When something breaks, it will be written up rather than quietly fixed.
