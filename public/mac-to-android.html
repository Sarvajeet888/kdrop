Send files from a Mac to an Android phone

Android File Transfer has been unreliable for years. This needs no cable and no software on either side.

Open K-Drop See the steps

Step by step

  1. On the Mac, open K-Drop in Safari or Chrome.
  2. On Android, scan the QR code with the camera.
  3. Drag files from Finder onto the drop area on the Mac.
  4. Tap Accept on the phone.

Worth knowing

Drag straight from Finder

No file picker needed — drag the selection onto the page.

Chrome on the Mac handles bigger files

Safari holds an incoming file in memory. For very large transfers to the Mac, use Chrome. Sending from Safari is fine.

Folder structure

Choosing a folder sends every file inside it, with names preserved.

Questions

Do I need Android File Transfer?

No. Nothing to install on either device.

Does it work the other way, Android to Mac?

Yes, the same session works in both directions.

Does it work over USB?

No, this is network-based. No cable involved.

How it works underneath

K-Drop opens a connection directly between the two browsers. Our server introduces them to each other and then stops being involved — it never sees the file. When a network blocks a direct connection, the file is encrypted on your own device with a key derived from your PIN, which we never receive, and passed through our relay as data we cannot read. Nothing is written to disk on our side.

Full detail is in the documentation.
